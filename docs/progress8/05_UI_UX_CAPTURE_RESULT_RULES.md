# 05 — UI and UX Rules

## Capture Page

Capture page harus sederhana:
- instruksi singkat,
- kamera preview,
- shutter,
- retry,
- loading.

Tidak boleh:
- YOLO-FIRST,
- AI realtime switch,
- lens selector custom,
- debug chips,
- status model bertumpuk,
- realtime bounding overlay.

## Result Page

Result page menampilkan:
- annotated image,
- risk status,
- prediction window,
- tree height estimate,
- clearance estimate,
- YOLO summary,
- AI validation summary,
- GPS summary,
- map link,
- developer link.

## Developer Page

Developer page boleh menampilkan raw session, raw YOLO, raw AI, raw geometry, file paths, dan diagnostic errors.

Debug tidak boleh tampil di operator capture page.
