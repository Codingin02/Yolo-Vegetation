# 00 — Progress 8 Plan C Overview

Progress 8 adalah Plan C. Plan C adalah jalur final untuk laporan akhir magang riset.

Plan C mengganti pendekatan realtime yang tidak stabil dengan pendekatan snapshot processing. HP hanya menjadi kamera, GPS client, dan uploader foto. Backend laptop memproses foto setelah shutter.

## Yang Dipertahankan

- Flask backend.
- Browser HP.
- Kamera HP.
- GPS HP.
- YOLO.
- AI vision.
- Python geometry.
- Growth prediction.
- Spreadsheet.
- Map.

## Yang Dibatalkan Untuk Final

- realtime YOLO sebagai core final,
- YOLO-FIRST live mode,
- AI realtime switch,
- debugging realtime frame loop,
- klaim multi-class realtime final.

## Kalimat Aman Untuk Laporan

Sistem monitoring vegetasi berbasis snapshot capture dengan YOLO-assisted object detection, AI-assisted visual validation, Python geometry, dan quarterly growth-risk prediction.

## Kalimat Yang Dihindari

Jangan tulis sistem final sebagai realtime YOLO multi-class. Jangan tulis AI menghitung clearance final. Jangan tulis sistem menggantikan pengukuran manual PLN.
