# Operator Command Center

Script:

```powershell
.\venv\Scripts\python.exe scripts\operator_command_center.py
```

Command dibagi menjadi:

- `SAFE NOW`
- `WAIT UNTIL MAKESENSE EXPORT`
- `WAIT UNTIL LABEL VALIDATION`
- `WAIT UNTIL EXPLICIT TRAINING APPROVAL`

Tujuannya agar operator tidak menjalankan import copy, build dataset final, atau training final sebelum waktunya.
