# Final System Limitations and Safety

Sistem ini adalah prototype riset magang, bukan pengambil keputusan final pemangkasan.

Batasan:

- Belum ada klaim akurasi YOLO sebelum training/evaluasi final.
- Belum ada klaim presisi jarak sebelum kalibrasi lapangan.
- ETA adalah estimasi berbasis threshold 3 meter prototype.
- Data lingkungan harus berasal dari manual CSV/sumber nyata, bukan asumsi.
- Keputusan tebang/pangkas final harus diverifikasi petugas PLN/ULP.
- Data PLN tidak boleh diunggah ke platform publik tanpa izin.
- Tidak ada aplikasi mobile; HP hanya browser field client.
