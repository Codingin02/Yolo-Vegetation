Field Capture Browser

HP adalah browser field client untuk kamera, GPS, input manual, preview, dan hasil prediksi. Laptop tetap menjadi server AI dan output resmi tetap CSV/spreadsheet-ready plus map report.

Gunakan HTTPS tunnel untuk izin kamera/GPS di HP. Jika model custom belum ada, sistem tetap berjalan dalam `MODEL_NOT_READY` + manual/provisional safe mode tanpa fake detection.
