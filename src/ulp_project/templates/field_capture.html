Field Capture Browser

HP adalah browser field client untuk kamera, GPS background, overlay YOLO/geometri, shutter capture, dan laporan CSV/map. Laptop tetap menjadi server pemrosesan field-trial.

Jika model custom belum tersedia, status tetap MODEL_NOT_READY dan detections kosong. Debug COCO hanya opt-in untuk uji overlay, bukan hasil final.
